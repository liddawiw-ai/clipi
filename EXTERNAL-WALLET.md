# External app checkout and withdrawals

The native app and the companion Worker must be released together. Existing PI Browser packs use their own catalog. The native pack tiers are 1, 2, 5, 10, 20, 50 and 100 USD. A dollar buys 1,000 diamonds by card or store billing, or 1,200 using a server-issued PI quote. The native Firebase account that starts checkout owns the credited diamonds.

## Merchant configuration

- Direct Android APK uses Stripe Checkout for cards and Google Pay on eligible devices. Set the Worker secrets `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET`. Register `/external-checkout/webhook` on the production Worker for checkout.session.completed, checkout.session.async_payment_succeeded and charge.refunded. Enable Google Pay in Stripe. No card data is collected in Clipi.
- PI runs on the registered mainnet Worker with its existing `PI_NETWORK_API_KEY` and D1 binding. The external handoff is `/external-checkout`. CoinGecko supplies the PI/USD price for asset `pi-network`. An optional `COINGECKO_DEMO_KEY` increases availability. A quote expires after five minutes. Completion of an approved transaction can be retried after expiry.
- For a store build, use the EAS production profile or set `CLIPI_DISTRIBUTION=store` at config evaluation. Configure one-time consumable products `clipi_diamonds_1000`, `2000`, `5000`, `10000`, `20000`, `50000` and `100000` (each with the same prefix) and their USD base prices. Register them in RevenueCat for Google Play or Apple. The app reads `EXPO_PUBLIC_RC_GOOGLE_KEY` or `EXPO_PUBLIC_RC_APPLE_KEY` (public SDK keys). The Worker needs the corresponding RevenueCat app ID in `RC_ANDROID_APP_ID` / `RC_APPLE_APP_ID` and the secret `RC_WEBHOOK_SECRET`. Configure RevenueCat's webhook at `/external-checkout/store-webhook` with Authorization set to Bearer followed by a space and that secret. Sandbox events never credit a production wallet.
- Cash withdrawals use the existing server-managed earnings wallet measured in points (one point per USD cent). They require an approved, funded Tremendous production account, the Firebase Functions secret `TREMENDOUS_API_KEY`, the wallet PIN and App Check configured for the actual distribution and signing key. The country list uses ISO 3166-1. Each country shows USD-denominated bank or wallet products returned by the merchant's live catalog. Recipient bank details are entered on the provider's hosted redemption page. Creating a reward issues a redemption link, it does not confirm a bank deposit.
- The purchased-diamond ledger, wheel practice balance, and settled cash earnings are separate. Changing a diamond price does not fund a host's cash earnings. Withdrawals use the existing minimum of 2,000 funded points and the 15-day interval. An unresolved provider response reserves the amount and can be resumed with the original request.
